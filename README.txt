GALAXY DIGITAL PARTNERS WEBSITE

FILES
- index.html: website structure and content
- style.css: design, colors, layout, responsive styles
- script.js: mobile menu, reveal animation, active navigation
- assets/galaxy-banner.jpeg: supplied Galaxy Digital banner (included as a project asset)

HOW TO RUN
1. Extract the ZIP.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html.
4. Right-click and choose "Open with Live Server" (if you have the Live Server extension).
   Or double-click index.html to open it in your browser.

BEFORE PUBLISHING
- Replace YOUR-EMAIL@example.com in index.html with the client's official email.
- Confirm all service descriptions and claims with the client.
- This is a front-end sample. The contact button opens the visitor's email app; it is not a database-backed form.
- The dashboard illustration is decorative and does not display real advertising metrics.
